# AI × Computational Neuroscience Portfolio

A bespoke, responsive portfolio for an AI/software developer building toward computational neuroscience.

## Included
- `index.html` — complete page structure and portfolio content
- `styles.css` — responsive editorial design system, motion, custom components
- `script.js` — scroll reveals, magnetic interactions, custom cursor and animated neural visual

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with the public contact email you want to use.
2. Replace the GitHub placeholder URL with the intended public GitHub profile.
3. Review the quantified profile statements in the Evidence section and adjust them to the exact wording you want publicly.
4. Add real project URLs where desired.
5. Deploy the folder to GitHub Pages, Netlify, Vercel or another static host.

## Design direction
Warm cream / ink / muted oxblood / sage, editorial typography, asymmetric composition, restrained motion and an animated neural canvas rather than stock imagery.
